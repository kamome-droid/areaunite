# 公開前に差し替えが必要なもの

**いま入っているコンテンツは全部ダミー**。関係者に見せるときに
「2026年の確定情報」と誤解されないよう、ひと目でダミーと分かる形にしてある。

| 場所 | 中身 | 差し替え先 |
|---|---|---|
| `items/*.md`（30件） | `MOVIE TITLE A` `DJ NAME B` のような通し名。説明文は「ここに説明文が入ります。」の繰り返し | 実際の作品・出演者・出店 |
| 同上の画像 | グレーの `IMAGE` 画像 | 実際のスチル・写真 |
| `sponsors/*.md`（8社） | `SPONSOR A`＋グレーの `LOGO A` 画像 | 実際の協賛社とロゴ |
| `event/2026.md` の `guests` | `RIDER NAME A`〜`T`（20名） | 実際の来場ライダー |
| 同 `supporters` | `後援団体 A`〜`D` | 実際の後援団体 |
| 同 `ticketUrl` | `https://example.com/ticket` | 実際の購入ページ |
| 同 `prVideo` | 無関係な公開動画 | 完成したPRムービーのURL |
| 同 `address` / `accessNotes` | 仮の住所と案内文 | 白馬五竜の実際の情報 |
| 同 `mapEmbed` | 暫定で白馬五竜スキー場を指している。住所を入れれば不要 | — |
| `public/images/items/_dummy/` `public/images/sponsors/_dummy/` | グレーの仮画像 | 不要になったらフォルダごと削除 |

**ダミーは `draft` を付けていない**ので、そのまま公開されてしまう。
本番に出す前に必ず実データへ差し替えること。
