# 公開前に差し替えが必要なもの

表示を確認するために入れた仮のデータ。**このまま公開してはいけない。**

| 場所 | 内容 | 差し替え先 |
|---|---|---|
| `event/2026.md` の `prVideo` | 無関係な公開動画 | 完成したPRムービーのURL |
| `event/2026.md` の DAY 2 | 中身は空（該当項目が無いので「準備中」と出る） | 2日目のプログラム。項目側に `day: day2` を付ける |
| `items/*.md` の `runtime`（14件） | 適当な分数 | **実際の上映時間**（「天地」の10分のみ実データ） |
| `items/ametsuchi.md` の `video` / `gallery` | 無関係な動画と自動生成した仮画像 | 予告編URLとスチル |
| `public/images/items/_dummy/` | 仮画像3枚 | 不要になったらフォルダごと削除 |
| `items/` の出演者7件（ライブ・トーク・DJ） | 架空の出演者名と紹介文 | 実際の出演者 |
| `items/` の出店6件（フード・ショップ） | 架空の出店名と紹介文 | 実際の出店 |

出演者と出店は `draft: true` なので、**本番ビルドには出ない**（開発サーバーでは見える）。
上映時間とPRムービーは draft ではないので、**そのまま公開されてしまう**。ここが要注意。
